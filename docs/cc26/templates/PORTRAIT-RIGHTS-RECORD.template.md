# V5.4 homepage portrait: rights record

Copy this file to `docs/home-v5-4/PORTRAIT-RIGHTS-RECORD.md` and fill in every field. Replace each `<…>`.

`scripts/home/validate-v54-portrait.mjs` refuses a replacement portrait while any field below is empty, still holds a `<…>` placeholder, or says TBD.

Keep the signed documents themselves (licence, model release, invoice) in the company's contract store. They contain personal data, so they do not belong in this repository. Record only their reference numbers here.

| Field | Value |
|---|---|
| Asset file | public/home-v54/v54-portrait.png (and the derived public/home-v54/v54-portrait-base.png) |
| Source | <commissioned shoot / stock library and asset ID> |
| Licensor / copyright owner | <legal name of the photographer, studio or stock agency> |
| Photographer | <name> |
| Licence or assignment reference | <contract, invoice or licence number> |
| Licence scope | <e.g. perpetual, non-exclusive or exclusive commercial licence; or full copyright assignment> |
| Model release reference | <signed model release ID; for stock, the agency's model-release reference> |
| Model is 18 or over | <yes, confirmed in the release> |
| Permitted uses | <website, app, paid social and search advertising, print; education-services marketing> |
| Editing, cropping and retouching permitted | <yes: cut-out, greyscale conversion, background removal, compositing with UI cards> |
| Sensitive-use restrictions | <none, or the agency's restrictions and confirmation that education marketing is allowed> |
| Territory and duration | <worldwide; perpetual, or the end date> |
| AI training or generation | <confirm the image is NOT generated from, or likening, any identifiable third party> |
| Approved by (Nextwise) | <name, role, date> |
| Design approval of the composited homepage | <name, date, link to the approved screenshots> |
